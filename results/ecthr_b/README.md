# ECtHR-B results

- `metrics.json` contains global and labelwise conformal metrics at alpha 0.05, 0.10, and 0.20.
- `summary.json` contains the compact global comparison at alpha 0.10.

The run used 500 validation cases for calibration and 500 test cases for evaluation. Large generated models, score tables, and raw reasoner traces are intentionally excluded from Git.
